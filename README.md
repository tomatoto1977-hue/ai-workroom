# AI作業室｜秘密基地 最適版

11担当AI（統括AI＋専門10担当）による安全設計のAI作業室です。

## 正本フロー
調査 → 企画 → 制作 → 品質確認 → 実装 → 統括

## 11担当
統括AI / 市場調査AI / 競争戦略AI / 企画AI / 情報収集AI / 予算AI / 文章化AI / エビデンスAI / 動画制作AI / 編集AI / 実装AI

## 95点品質ゲート
100点満点で、事実性25・目的適合20・具体性20・伝達性15・実装可能性10・安全性10を評価し、95点以上を合格とします。未達時は改善・再評価を行います。

## 安全ルール
- テーマは節約に限定せず、毎日の情報収集から有用な題材を選ぶ
- 特定人物、とくに芸能人への依存を避ける
- 著作権侵害につながる画像・動画・音源・文章・キャラクター等は使用しない
- 自作または利用条件を確認した素材のみ使用
- 未確認情報は断定せず、出典・確認日を残す
- 公開・投稿・外部操作・金銭操作は人間承認を必須とする

## 運用
AIは制作・確認・受け渡しを支援し、公開前の最終判断は人間が行います。
