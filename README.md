# AI作業室｜秘密基地 最適版

11担当AI（統括AI＋専門10担当）による安全設計のAI作業室です。

## 正本フロー
調査 → 企画 → 制作 → 品質確認 → 実装 → 統括

## 11担当
統括AI / 市場調査AI / 競争戦略AI / 企画AI / 情報収集AI / 予算AI / 文章化AI / エビデンスAI / 動画制作AI / 編集AI / 実装AI

## 95点品質ゲート
100点満点で、事実性25・目的適合20・具体性20・伝達性15・実装可能性10・安全性10を評価し、95点以上を合格とします。未達時は改善・再評価を行います。

## 安全ルール
- テーマは節約に限定せず、毎日の情報収集から有用な題材を選ぶ
- 特定人物、とくに芸能人への依存を避ける
- 著作権侵害につながる画像・動画・音源・文章・キャラクター等は使用しない
- 自作または利用条件を確認した素材のみ使用
- 未確認情報は断定せず、出典・確認日を残す
- 公開・投稿・外部操作・金銭操作は人間承認を必須とする

## 動画工場ショート動画制作方式 v15
今回のSNS動画で有効だった要素を標準化します。

AI画像を毎回テーマに合わせて生成 → TikTokセーフエリアに自動配置 → テロップ → ぬるっとした場面切替 → ズーム/パン → 強めのBGM/効果音 → ナレーション（利用可能なTTSを接続） → 完成動画QA → 人間レビュー

- 1080×1920を標準
- 上・右・下のTikTok UI領域を避け、中央〜左に重要情報を配置
- AI画像は毎回テーマ別に生成し、転載・人物・ロゴ・著作権キャラクター等を避ける
- テロップは単なる重ね置きではなく、ポップイン、強調語、背景プレート等で視線誘導
- シーン切替はクロスディゾルブ＋モーションで急なカット感を減らす
- BGMと効果音はナレーションを邪魔しないダッキング設計を前提とする
- ナレーションはプロバイダ接続式。未接続時は制作を止めずREVIEWにできる
- 自動投稿、外部操作、金銭操作、認証情報利用はしない
- 完成動画は自動QA後も人間レビュー必須

実装ファイル: video_factory/shorts_pipeline_v15.py

## Obsidian 自動同期（Local REST API）

- index.html の継続記憶カードに、ObsidianのLocal REST APIプラグイン接続欄を追加しました。
- 設定後、ブラウザ内記憶をObsidianの `AI作業室/01_学習コンテキスト/AI作業室_継続記憶.md` と自動で統合します。起動時に保管庫の同ファイルを読み込み、保存時には少し待ってから同期します。
- 同期は端末の localhost に限定し、APIキーはそのブラウザの localStorage に保存します。APIキーをRenderやAI APIへ送信しません。
- 初回はObsidianでLocal REST APIコミュニティプラグインを導入し、APIキーとCORS許可元を設定してください。手順は [docs/obsidian-auto-sync.md](docs/obsidian-auto-sync.md) を参照。プラグインは通常HTTPS 27124番を使います。HTTP 27123番を使う場合は、プラグイン側でHTTPを有効にし、localhostだけにバインドしてください。
- 接続できない場合も、ブラウザ内記憶は保持し、従来のMarkdown手動入出力を利用できます。同期ステータスを成功表示できた場合のみ、書き込み成功として扱います。
- 同期時はメイン記憶ファイルに加えて、ルール・学習・リサーチ・制作/監査・改善実験の各フォルダに個別ノートのミラーを生成します。読み戻しの正本はメイン記憶ファイルです。カテゴリ別ミラーは整理・閲覧用で、直接編集しても次回同期で保持されるとは限りません。
- 注意：ObsidianとAI作業室を同じ端末・同じブラウザで開く構成が基本です。iPhone上のObsidianとPC上のブラウザのように端末が異なる場合、 localhost は接続先端末自身を指すため、そのままでは同期されません。

## 継続記憶・Obsidian連携（追加）
- AI作業室のブラウザ内に、ユーザー指定ルール・テーマ調査ログ・実行結果の要約を最大100件保存します。
- 次回実行時は関連するルールと調査メモを最大650文字程度に絞り、制作AIと品質監査AIへ渡します。URL長とトークン使用量を抑えるため、保管庫全体は送信しません。
- 「Markdownを書き出す」で `AI作業室_継続記憶.md` を出力し、Obsidianの保管庫へ保存できます。Obsidian側で編集した後は「Obsidianから読み込む」で反映します。
- 生成された調査・台本は `unverified` / `review_required` 等の状態を付け、独立検証済みの事実と混同しません。ユーザーが保存したルールは `user_confirmed` として区別します。
- ブラウザ保存は端末・ブラウザ単位です。RenderからローカルのObsidian保管庫へ直接アクセスする構成ではありません。端末データ消去や別ブラウザへの移行に備え、定期的にMarkdownを書き出してください。
- APIの `MEMORY_REQUIRED=true` を設定した場合、記憶コンテキストなしの実行は503で停止します。既定では初回利用を壊さないよう任意読込とし、UIから利用可能な記憶を自動添付します。
- 継続記憶の読込・書出しは外部投稿、金銭操作、認証情報の利用を行いません。

## 運用
AIは制作・確認・受け渡しを支援し、公開前の最終判断は人間が行います。


## 動画工場 v15 音楽ルート

動画工場の音楽は4系統に統一されています。

- ACE-Step（PCローカルAI）：自動生成・日本語ボーカル
- Suno（手動）：動画工場が制作指示を作り、Sunoでユーザーが生成した音源を取り込む
- 外部音源：MusicSeed / BandLab / GarageBand等の書き出し音源を取り込む
- 音楽なし：ナレーション中心

Web画面では音楽方式・ジャンルを選択でき、外部音源は12MB以下のWAV/MP3/M4A/AAC/FLAC/OGGを取り込めます。Sunoは自動ログイン・課金・生成・投稿を行わず、手動生成を前提とします。

安全ゲート：自動投稿OFF / 金銭操作OFF / 認証情報利用OFF / 人間承認必須。


## 継続記憶の保守・過去バグ再発防止

保管量が増えても重複や古い知識をそのまま次の作業へ渡さないよう、ブラウザ内記憶の非破壊点検を追加しました。「蓄積メモを点検」で重複候補、90日以上経過した調査/実行記録、再発防止情報が不足した不具合候補、ルール矛盾の可能性、保存上限への接近を確認できます。点検は候補抽出のみで、削除・上書き・ルール変更は自動で行いません。運用詳細は [docs/obsidian-maintenance.md](docs/obsidian-maintenance.md) を参照してください。
