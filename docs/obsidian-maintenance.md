# Obsidian 継続記憶の保守運用

## 目的
保存量が増えたときに、重複・古い調査メモ・再発防止策の不足・ルール矛盾の可能性を見つけ、次の作業に過去の学びを反映する。保管庫の削除や自動上書きは行わない。

## AI作業室の現在の点検
- 記憶カードを開いたとき、保存状況の更新時にローカルの保存メモを点検する。
- 「蓄積メモを点検」でレポートを更新できる。
- 検出対象：重複・類似候補、90日以上経過した調査/実行記録、原因・対策・テスト情報が不足した不具合候補、矛盾の可能性があるユーザー確定ルール、保存件数が80件以上の容量警告。
- 点検はヒューリスティックによる候補抽出であり、正確な意味理解を保証しない。候補は人が確認する。
- 自動削除、自動アーカイブ、自動ルール変更はしない。ルールはユーザー確定を維持する。
- 現行のブラウザ記憶上限は100件。上限前にMarkdownを書き出し、Obsidian側で保管・整理する。

## Obsidian側の推奨構造
- `00_絶対ルール/` — 安全、著作権、人間承認、予算
- `01_学習コンテキスト/` — 再発防止、採用した改善、確定した知見
- `02_リサーチ/` — 日付、出典、確認日を含む調査記録
- `03_制作・品質監査/` — 成果物、監査、修正履歴
- `04_改善実験/` — 仮説、試験、結果、採否
- `90_アーカイブ/` — 古くなった情報。削除せず、参照元・リンクを確認して移動

## バグ記録の標準フォーマット
```markdown
# 不具合名
- 発生日:
- 対象プロジェクト/バージョン:
- 症状:
- 再現条件:
- 根本原因:
- 修正内容:
- 再発防止ルール:
- 確認テスト:
- 検証結果: 未検証 / pass / fail
- 状態: open / fixed / monitoring / archived
- 関連ファイル・リンク:
```

## 定期運用
1. 週1回を目安にAI作業室の点検レポートを確認する。
2. 月1回、MarkdownをエクスポートしてObsidianへ保存し、バックアップを取る。
3. 重複候補は統合前に参照リンクと日付を確認する。
4. 古い記録は現行ルールに昇格させず、必要に応じてアーカイブする。
5. 不具合を修正したら、再発防止ルールとテスト結果を必ず記録する。
6. 新しい作業前には関連する確定ルールと未解決不具合を読み込む。

## 制約
Render上のWebアプリは、利用者の端末にあるObsidian保管庫を直接走査できない。現段階の自動点検対象はAI作業室のブラウザ内記憶であり、Obsidian全体の整理にはMarkdownの書き出し/読み込みが必要。定期的なバックグラウンド実行は保証されず、アプリを開いた際や手動点検時に実行する。


## Obsidian Local REST API 自動同期

自動同期はAI作業室のブラウザと、同じ端末で動作しているObsidianを接続します。Obsidianの保管庫全体を走査せず、専用の継続記憶ファイルを正本として同期し、分類別フォルダには閲覧用の個別ノートをミラーします。

1. Obsidianの設定 → コミュニティプラグインから **Local REST API** をインストールして有効化します。
2. プラグインが表示するAPIキーを控えます。キーは共有・公開しないでください。
3. プラグイン設定でCORS/Allowed originsに `https://ai-workroom.onrender.com` を追加します。プラグインがHTTPSオリジンを許可できる場合のみ利用してください。
4. AI作業室を、Obsidianと同じ端末のブラウザで開きます。
5. 継続記憶カードでURLとAPIキーを入力し「接続設定を保存・同期」を押します。Local REST APIは通常HTTPSの27124番を使いますが、自己署名証明書をブラウザが信頼していないと接続に失敗します。HTTPの27123番を使う場合は、プラグイン設定でHTTPを明示的に有効にし、バインド先を127.0.0.1のままにしてください。
6. ステータスが「同期成功」になれば完了です。専用ファイル `AI作業室/01_学習コンテキスト/AI作業室_継続記憶.md` にまとめて保存します。

### 自動処理

- 記憶の新規保存・更新後、約2秒待ってから同期します。
- AI作業室を開くと、設定済みの場合は専用ファイルを読み込み、IDを使って既存メモと統合してから書き戻します。
- 同期では既存メモを自動削除しません。正本ファイルからID単位で読み込みます。分類別ノートは閲覧用ミラーであり、直接編集した内容は次回同期で保持される保証がありません。編集する場合は正本ファイルを使ってください。
- 接続失敗時はローカルのブラウザ記憶を保持し、ステータスに原因を表示します。手動Markdown入出力も残しています。

### セキュリティと制限

- APIキーはそのブラウザのlocalStorageに保存されます。共有端末では設定を保存せず、不要になったらブラウザデータから設定キー `aiworkroom_obsidian_local_rest_v1` を削除してください。
- APIキーをRenderやOpenAI APIへ送信するコードはありません。ただし、ブラウザ内のスクリプトからローカルAPIへ接続するため、許可するCORSオリジンをAI作業室に限定してください。
- 初期設定はlocalhostに限定しています。PCのObsidian保管庫へiPhoneから接続する用途には使えません。端末間同期にはObsidian Sync等で同じ保管庫を端末側に同期し、各端末のローカル設定を個別に行う必要があります。
- ブラウザ・プラグイン・OSのセキュリティ設定によってlocalhost接続がブロックされる場合があります。接続できない場合はAPIキーを外部サイトに貼り付けず、Markdown手動入出力を使ってください。
- この機能は専用ファイルのみを対象にし、保管庫の全ファイルを検索・整理・移動しません。
