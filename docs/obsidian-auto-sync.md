# Obsidian 自動同期セットアップ

この機能は、AI作業室のブラウザ内記憶と、同じ端末で動作しているObsidian保管庫の専用Markdownファイルを同期します。保管庫全体を読み書きするものではありません。

## 1. Obsidian側
1. Obsidianの「設定」→「コミュニティプラグイン」で **Local REST API** を検索してインストール、有効化します。
2. プラグイン設定でAPIキーを確認します。第三者へ共有しないでください。
3. CORS/Allowed originsを設定できる場合は、AI作業室のオリジン `https://ai-workroom.onrender.com` のみを許可します。ワイルドカード `*` は使用しないでください。
4. プラグインが表示するURL/ポートを確認します。一般的な既定値は `https://127.0.0.1:27124` ですが、自己署名証明書をブラウザが信頼していないと接続できません。簡易接続としてHTTPの `http://127.0.0.1:27123` を使う場合は、プラグイン設定でHTTPを明示的に有効化し、バインド先を127.0.0.1に保ってください。

## 2. AI作業室側
1. Obsidianと同じPC（または同じiPhone）上のブラウザで [AI作業室](https://ai-workroom.onrender.com) を開きます。
2. 「継続記憶・Obsidian」まで移動します。
3. URL欄を、プラグインで実際に有効にしたlocalhost URLに合わせます。HTTPSの自己署名証明書が信頼されていない場合、ブラウザが接続を拒否することがあります。
4. APIキーを入力して「接続設定を保存・同期」を押します。
5. 「同期成功」と表示されることを確認します。

正本：`AI作業室/01_学習コンテキスト/AI作業室_継続記憶.md`

同期時には、ルールは `00_絶対ルール`、調査は `02_リサーチ`、制作・監査は `03_制作・品質監査`、改善実験は `04_改善実験` などへ個別ノートの閲覧用ミラーも作成します。読み戻しは正本ファイルから行います。カテゴリ別ミラーを直接編集しても変更が維持される保証はないため、編集は正本で行ってください。

## 3. 動作
- AI作業室でルールや実行結果を保存すると、約2秒後に自動同期します。
- ページ起動時にも保存先の記憶を読み込み、既存のIDを使って統合します。
- 手動のMarkdown書き出し・読み込みも引き続き利用できます。
- 接続できない場合はブラウザ内記憶を消さず、画面にエラーを表示します。

## 4. 安全上の注意
- APIキーはブラウザのlocalStorageに保存されます。共有端末では設定を保存しないでください。
- APIキーはRenderやAIモデルへ送信しません。CORS許可元を限定してください。
- `127.0.0.1` はそのブラウザを動かす端末自身です。PCにある保管庫へ、別端末のiPhoneからそのまま接続することはできません。
- ブラウザやOSがHTTPSサイトからlocalhostへのアクセスを制限する場合があります。接続に失敗したら、APIキーを別の場所に貼り付けず、従来のMarkdown入出力を使ってください。
- 同期対象は専用ファイルだけです。Obsidian保管庫全体の自動走査・自動移動・自動削除は行いません。
